# FUTSAL IQ: versión de prueba

Juego educativo de fútbol sala para niños de 9 a 11 años, para móviles y tablets.
Esta es una versión de prueba, sin lanzar: **https://jep004.github.io/futsal-iq-pruebas/**

La versión 1.0, en construcción (con el arte nuevo): https://jep004.github.io/futsal-iq-pruebas/v1/

Solo contiene las páginas jugables (`index.html` y `v1/index.html`). El juego guarda el progreso en el propio dispositivo; no envía datos a ningún sitio.
