# FUTSAL IQ: versión de prueba

Juego educativo de fútbol sala para niños de 9 a 11 años, para móviles y tablets.
Esta es una versión de prueba, sin lanzar: **https://jep004.github.io/futsal-iq-pruebas/**

Solo contiene la página jugable (`index.html`). El juego guarda el progreso en el propio dispositivo; no envía datos a ningún sitio.
